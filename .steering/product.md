# 产品概述

SyncUI 是一个跨平台目录对比与同步桌面应用（Tauri v2 + React + Rust）。用户把「本地目录」和「远程/挂载目录」拖进窗口，一键对比差异，勾选后执行同步，替代手敲 `rsync` 或逐个点「覆盖/跳过」的复制粘贴。

远程目录（sftp / smb / nfs 等）挂载后对程序而言就是普通文件系统路径——引擎只操作两个路径，不关心底层协议。当前主要在 Linux（Ubuntu）验证，macOS / Windows 理论支持但未验证打包。

## 核心能力

- **镜像同步（mirror）**：单向，将本地推送至远程，保持远端与本地一致。
- **双向同步（twoway）**：基于「上次同步快照」做三方对比（本地 L / 远程 R / 基线 B），准确区分「删除」与「新增」，并识别冲突。
- **冲突策略**：较新优先 / 强制用本地 / 强制用远程 / 跳过，四选一。
- **差异可视化**：按动作（上传 / 下载 / 删除 / 冲突 / 一致）展示，逐项勾选；上传下载默认预选，删除与冲突需手动勾选防误操作。
- **实时进度**：扫描（`scan-progress`）与同步（`sync-progress`）均有节流事件驱动进度条和日志，不冻结界面。
- **原子写入**：临时文件 + 原子重命名，保留源 mtime，保证幂等。
- **哈希校验**：可选 BLAKE3 内容哈希，精确判断文件是否真正变更。
- **并行执行**：有界 worker 池并发同步，并发数 1–32（默认 4）。
- **忽略规则**：逗号分隔的名称列表，默认剪枝 `.git`、`node_modules` 等。

## 典型工作流

```text
拖入本地目录 ──► 拖入远程目录 ──► 调选项 ──► 对比 ──► 勾选 ──► 同步 ──► 自动重对比
  左侧拖放区       右侧拖放区      模式/策略   compare_dirs  差异表  sync_entries   确认结果
```

## 主要使用者

- **终端用户**：需要在本地与挂载远端之间做可视化增量同步，不想记 rsync 参数。
- **后续 Agent / 开发者**：在 Rust 引擎上扩展同步策略、在 React 上扩展交互；改代码时须遵守 `structure.md` / `tech.md` 的约定。
